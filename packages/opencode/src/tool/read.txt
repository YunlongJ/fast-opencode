Reads a single file from the local filesystem with high performance and intelligent caching.

CRITICAL RULES:
1. SINGLE FILE ONLY: This tool reads exactly ONE file per call
2. MULTIPLE FILES: When reading 2+ files, you MUST use 'read_multiple' tool instead
3. NEVER use this tool in a loop or batch - use 'read_multiple' for batch operations

PERFORMANCE FEATURES:
- Intelligent caching: Frequently accessed files are cached for instant retrieval
- Streaming reads: Large files are processed efficiently without loading entirely into memory
- Binary detection: Automatically skips binary files using fast extension checks
- Parallel ready: Optimized for concurrent execution with proper resource locking

USAGE GUIDELINES:
- filePath: Must be an absolute path (e.g., "/home/user/project/src/main.ts")
- offset: Line number to start from (0-based). Use for reading specific sections of large files
- limit: Max lines to read (default 2000, max 5000). Increase for large files, decrease for quick checks

WHEN TO USE OFFSET/LIMIT:
- Large files (>2000 lines): Read in chunks using offset to navigate
- Log files: Use offset to jump to recent entries
- Configuration files: Usually read entirely (no offset/limit needed)
- Code review: Use offset to focus on specific functions/classes

OUTPUT FORMAT:
- Returns content with line numbers (cat -n style, starting at 1)
- Lines >2000 chars are truncated with "..."
- Truncation warnings indicate if more content is available
- Binary files and images are handled appropriately

EXAMPLES:
- Read entire file: { "filePath": "/project/src/app.ts" }
- Read specific section: { "filePath": "/project/logs/app.log", "offset": 1000, "limit": 500 }
- Quick check first 100 lines: { "filePath": "/project/README.md", "limit": 100 }
